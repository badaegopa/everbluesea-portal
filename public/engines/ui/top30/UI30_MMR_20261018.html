되풀이되는 구조(관찰): 생계 충격(가격 인상)이 촉발 → 종교·학생 집단 합류로 확산 → 통행금지·발포·대량 구금으로 종결되는 1988년과 유사한 순서.

2021년 2월~현재

4-1. 관점 전환 — 붕괴 경로의 세 갈래

제4층 관점 전환 — 붕괴는 진화의 전환점

국가분석 총서는 봉기·붕괴를 억압으로 막아야 할 사건이 아니라 사회 진화의 전환점으로 읽고, 발화 이후의 경로를 세 갈래로 나눈다(총서 제1권 §3.2, 원문 상자 1-1 참조). 이 나라의 제도 탄성 E_A2 는 A2 = 0.1313 를 넘을 수 없다(E_A2 ≤ A2). 내부 충돌 C_internal 은 정본값이 없어 경로를 판정하지 않고, E_A2 조건과의 양립 여부만 적는다.

경로총서 조건이 나라(E_A2 ≤ A2)
White Dwarf (억압·잠복)E_A2 < 0.3, C_internal < 0.4양립 가능 — E_A2 가 조건 범위에 들 수 있다
Supernova (붕괴·재생)E_A2 0.3~0.5, C_internal > 0.5양립 불가 — E_A2 ≤ A2 < 0.3
Black Hole (내파·복원불가)E_A2 < 0.2, C_internal > 0.7양립 가능 — E_A2 가 조건 범위에 들 수 있다
